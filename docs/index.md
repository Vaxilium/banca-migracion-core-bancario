# Migración del core bancario — Banco Meridiano Austral

**Entidad 100 % ficticia. Todos los clientes, cuentas, movimientos e importes de este
repositorio son datos sintéticos generados por código con semilla fija. Cualquier
parecido con personas o entidades reales es coincidencia.**

Este repositorio demuestra, de punta a punta, cómo un Analista de Negocios / Analista
Funcional conduce la migración de un core bancario legado hacia un core moderno:
estrategia, análisis AS-IS, brechas funcionales, mapeo de datos, reglas de
transformación, tres ensayos de migración, conciliación contable, pruebas con Gherkin,
corte y reversa, gestión del cambio, riesgos y controles, y trazabilidad de requisitos.
